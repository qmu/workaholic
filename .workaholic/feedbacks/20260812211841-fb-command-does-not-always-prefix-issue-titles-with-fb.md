# /fb command does not always prefix issue titles with [FB]

When creating an issue via the `/fb` command, the resulting GitHub issue title is missing the "[FB]" prefix. The prefix should always be included in the title.

Source: GitHub issue #411 (https://github.com/qmu/workaholic/issues/411), filed by claude[bot], assigned to tamurayoshiya.
