# Add Strategy as a fourth /propose artifact type

`/propose` today emits three artifact types — Feedback, Mission, Ticket — and the ask is to extend that artifact model with a fourth: **Strategy**. Once Strategy is a first-class `/propose` artifact, it should also become possible to raise FB issues directly from Slack chat by announcing that a Strategy has ended, changed, or been created: such a Slack message should be usable as the trigger and the content for filing an FB issue, the same way Feedback/Mission/Ticket asks are handled today. Stated as a scope-extension request for the `/propose` command's artifact model.
