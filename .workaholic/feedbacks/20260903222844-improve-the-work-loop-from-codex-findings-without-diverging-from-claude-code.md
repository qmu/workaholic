# Improve the work loop from Codex findings without diverging from Claude Code

Source: https://github.com/qmu/workaholic/issues/969

When the work loop does not operate correctly under Codex, diagnose the failure from Codex's execution model and repair this repository. Use the simultaneous Claude Code trial as evidence, preserve the shared behavioral contract, separate agent-specific adapters from common semantics, and incorporate findings from both environments rather than optimizing either one at the other's expense.
