# Refuse an ask the loop wrote to itself

## Goal

Five consecutive FB roots in one day that no human wrote: each a record a routine session
authored about the loop's own self-proposed apparatus, each proposed, ticketed, implemented
and merged by the next ticks, each link refining the link before it — until the operator
abandoned the direction mid-drive. Their verdict: a waste, and worse, real development
stopped entirely while the loop busied itself.

Every gate held. None of them asks *who wanted this*. That is the gate this mission adds.

## Experience

Only a human's ask, or a strategy a human authored, originates a mission. A record a
routine wrote about the loop's own apparatus reaches no proposal; a proposal refining a
prior self-proposal is refused by name at the bar; and a window in which only the loop has
spoken stops origination instead of feeding it.
