# A repository can say what runs against it

## Summary

Scheduled routines lived only in the Claude Code Web account, so nothing in a repository could answer "what runs against this repo, and is it what we meant?". The routines surface is now inspectable and safely mutable from the repository: a survey reports every routine that targets it with per-field drift, and add/refresh/remove are gated on a digest over the exact confirmed body.

## Key Changes

- The survey reports each routine's trigger, schedule, target, and per-field drift against the plugin's templates; an unreachable account is `checked: false` with no routines key, so "could not look" never renders as "nothing runs here".
- Add, refresh, and remove are gated by a digest over the confirmed body, closing substitution and silent batching between confirmation and execution.
- "Remove" means disable, stated plainly, because the routines API has no delete.
