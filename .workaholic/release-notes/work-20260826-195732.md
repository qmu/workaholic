# Retire the always-on mission-lens hook

## Summary

The always-on mission lens (`hooks/mission-lens.sh`, UserPromptSubmit + Stop) is
retired: the hook, its registrations, its tests and every live-behavior
reference are deleted in one change ([PR #626](https://github.com/qmu/workaholic/pull/626)).
The plugin now registers no Stop hook and ships one always-on lens, the policy lens.

## Key Changes

- The `Stop` key is deleted from hooks.json outright — mission-lens was its only registrant.
- The resolve.sh absolute-path-caller test pin is re-pointed at `progress.sh`, so no coverage is lost.
- Eleven live-behavior documents corrected; historical records keep the eleven-missions measurement as history.

## Changes

### Removed

- `hooks/mission-lens.sh` and its two hooks.json registrations; three lens test functions, their registry rows and the `SCRIPTS.missionLens` constant.

### Changed

- CLAUDE.md, README.md, mission/gather skill docs, five script header comments, the drive-loop runbook's `dirty_workspace` row, and the `terms/` glossary now describe the post-retirement behavior; `outputs/` regenerated; version bumped to v1.0.224.
