# Relay Codex Slack through its owning chat

## Summary

Codex worker ticks can now return closed, versioned Slack intents to the conversation that owns the connector. Durable status distinguishes requested operations from parent-acknowledged delivery and reports missing relay capability explicitly.

## Key Changes

- Keep Slack credentials and connector authority in the owning chat.
- Validate ordered operations and make retries idempotent with stable intent keys.
- Record pending, partial, malformed, unavailable, and delivered outcomes separately.

## Changes

### Changed

- Added the v1 worker-to-parent relay contract and acknowledgement validator.
- Added relay and acknowledgement modes to the self-contained Codex loop launcher.
- Documented parent execution and exact thread-resolution responsibilities.
- Released the implementation as v1.0.310.
