# Complete the agentic loop redesign

## Summary

Version 1.0.334 completes P3 through P9 of the agentic loop redesign. Interrupted work can resume from durable transport, dispatch, publication, polling, and delivery evidence while agents retain control of semantic planning.

## Key Changes

- Reconcile external effects from provider evidence before retrying.
- Capture QFS channel deltas durably before advancing the polling cursor.
- Keep runtime exclusion portable across systems with and without `flock`.

## Changes

### Added

- Added typed runtime, transport, publication, polling, and delivery contracts with portable generated workflow assets.

### Changed

- Routed manual and automatic entrypoints through shared observations and capability-selected adapters.
- Replaced implementation-shaped assertions with registry, receipt, recovery, and isolated-consumer behavior checks.

## Verification

- 6,886 workflow smoke checks and 77 focused agentic-loop tests passed.
- All 50 registered drills completed with 0 failures; 2 server drills were skipped by contract.
- Plugin build, metadata, documentation build, and Wrangler dry-run passed.
