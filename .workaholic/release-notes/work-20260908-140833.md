# Make Slack acknowledgements informative without notification noise

## Summary

Workaholic acknowledgements now tell people what was understood and what happens next. Related message bursts share one concise receipt while retaining durable handling state for every source message.

## Key Changes

- Define a human-centered acknowledgement contract
- Group related bursts without losing per-message state
- Validate semantic facts independently from natural prose

## Changes

### Changed

- Added deterministic acknowledgement facts for subject, source, status, and next action
- Added burst grouping with duplicate and malformed-input protection
- Documented flexible prose boundaries across work and notification guidance
