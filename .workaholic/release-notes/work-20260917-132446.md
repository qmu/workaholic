# Preserve capture failure reasons

## Summary

Channel observation now returns typed failures when inbox capture exits unsuccessfully or emits malformed output. The cursor stays in place so the next tick can retry the same provider page instead of treating unread input as quiet.

## Key Changes

- Preserve capture subprocess failure reasons
- Normalize unreadable diagnostics to `capture_unreadable`
- Keep retryable cursors stationary on observation failure

## Changes

### Changed

- Made capture failures explicit in observation outcomes
- Added regression coverage for malformed output and cursor preservation
