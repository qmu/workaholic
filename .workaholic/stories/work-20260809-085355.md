## 1. Overview

This branch erases the 🟣 purple-circle "Merged by `<@U…>`" notification shape from `workaholic:notify`'s reference documentation and every other place the plugin described it, per a direct developer ask (qmu/workaholic#317). Investigating the shape's actual poster found it had none: `[Consent]`, the routine that used to announce human merges, was retired 2026-08-06, so the shape was documenting a post nobody makes.

**Highlights:**

1. Removed the 🟣 shape from `notify/reference/notifications.md`, `notify/SKILL.md`, `drive/SKILL.md`, `drive/reference/routing.md`, and `CLAUDE.md`.
2. The auto/human merge distinction survives without a second emoji: `🚀 Auto Merge` is the only merge line `/implement` ever posts; a human merge is now silent and readable on GitHub.
3. Minted a follow-up ticket for two other, pre-existing stale shape references (`🟢`/`🟠`) noticed in the same files but outside this ticket's scope.

## 2. Motivation

The developer asked directly in #dev-workaholic (2026-08-09) to erase the purple-circle format entirely, filed as qmu/workaholic#317 and proposed as PR #320. The shape marked a human-merge finish line, distinguishing it from the unattended `🚀 Auto Merge` line — but nothing in the current system actually posts it: its only producer, the `[Consent]` routine, was retired 2026-08-06 at a stated accepted cost ("a human-merged pull request is now announced by nobody"). Erasing the shape aligns the documentation with that already-accepted reality rather than leaving a description of dead behavior on the books.

## 3. Changes

### 3-1. Erase the purple-circle (🟣) notification format ([639c4e19](https://github.com/qmu/workaholic/commit/639c4e19))

Removed the `🟣 Merged by <@U…>` shape from every source location that defined or described it, and rewrote the surrounding prose so the auto/human distinction it used to carry is stated explicitly instead: `🚀 Auto Merge`'s presence in a thread means an unattended ship; a `review` unit's thread stays at `🛠️ Implemented` even after a later human merge, which is readable on GitHub. Regenerated `outputs/workflows` and minted a follow-up ticket for adjacent stale `🟢`/`🟠` references left over from an earlier, incomplete reconciliation (P10).

## 4. Outcome

The 🟣 shape is fully erased — no file under `plugins/workaholic/`, `outputs/`, or `CLAUDE.md` defines, documents, or emits it (verified by grep and by the full local verification suite, 2448/2448 tests green). A developer can still tell an auto-merge from a human merge from the thread alone, without a dedicated emoji for the latter.

## 6. Successful Development Patterns

- Before replacing a documented notification shape, trace its actual poster: the shape had already gone fully dead (its emitter routine retired weeks earlier), which turned a "what replaces this" design question into "there is nothing left to replace."
