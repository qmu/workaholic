## 1. Overview

The release scan's non-overridable `secret` tier no longer hard-blocks the documented
Terraform wiring: an HCL assignment whose value is an unquoted `var.`/`local.`/`data.`/
`module.` reference is now subtracted by pass 2's reference exclusion, while a quoted or
literal HCL credential still flags exactly as before (qmu/workaholic#378).

**Highlights:**

1. The fix is one alternation added to the existing reference-subtraction list — the same mechanism as the `process.env`-class exclusions, no new rule shape.
2. `module.` joins the reported three: a nested module output is the same grammar class and was left uncovered by the report.
3. Four must-not-flag rows and one must-flag row join the shared gate table in `test-workflow-scripts.mjs`.

## 2. Motivation

Issue qmu/workaholic#378 reported that `api_token = var.cloudflare_api_token` — the
documented, correct way to wire a Terraform provider credential — was flagged as a hard
`secret` finding, blocking every branch touching such a stack on the one tier with no
override. Reproduced first against the base (`secret_grep` matched the reference form),
localized to pass 2's exclusion list, which knew the host-language env readers but no HCL
reference prefix. The subtraction requires the value to *begin* with the prefix, so in HCL
grammar it can only match a reference — a quoted `"var.x"` literal still flags.

### 3-1. Exclude HCL references from the secret rule ([22d190f5](https://github.com/qmu/workaholic/commit/22d190f5))

Extended `secret_grep`'s pass-2 `grep -Eiv` subtraction in `secret-patterns.sh` with
`var\.|local\.|data\.|module\.`, documented the addition in the file's header beside the
env-read exclusions, and added the paired gate rows to `test-workflow-scripts.mjs`.
`record-evidence.sh` is unaffected by construction — it shares only pass 1, and this
change touches pass 2 only. The generated `outputs/workflows` bundles carry the fix.
