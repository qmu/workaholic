# Refuse a commit that splits a rename

## Motivation

`commit.sh`'s default staging is `git add -u`, which by its own semantics stages tracked
modifications and deletions and leaves untracked files out. A convergent migration writes its
additions **untracked** and deletes the originals — so default staging takes exactly half of it.

That half merged. **50 concern records lost their content on `main`**, and a story body written the
same run was dropped while its index entry landed.

`commit.sh` already **warned** about untracked files. The warning fired on both, and both commits
went through, because a warning's enforcement is a human reading it — and an unattended run has no
such human.

## Outcome

**The refusal.** A staged deletion co-existing with an untracked file, under default staging, is
refused: both halves listed, three concrete repair lines, nothing committed, the working tree
untouched. It never fires on untracked files alone — they are routine, and a guard that fired on
them would be switched off within a day — and never when the caller already named `files...`.

**The rule.** Stated once in `workaholic:commit`: a caller that has just written a **new** file
passes it in `files...`. Referenced, not restated, by the one seam that needed it.

The two are complementary and the mission ordered them deliberately: a rule holds where somebody
follows it, a refusal holds everywhere — and with the refusal landed, a seam that forgets the name
now fails loudly instead of silently.

## Journey

**Open Decision 1 was ruled toward the gate, not the caller.** Leaving the deletion half unstaged
inside `migrate-concerns.sh` is precise and local — and it is one migration's fix that every future
migration must remember, and it edges against that script's measured *never touch the caller's
index* contract. One place catches every migration, including the ones not yet written.

**The false positive was accepted with its escape named.** A legitimate delete-here-add-there
commit is refused too, and the repair is to name the files — the caller stating its set rather than
inheriting it, which is the outcome the guard wants in both cases.

**The enumeration was the substance of the second ticket, and the report undercounted.** Eight call
sites, not two: forwarding wrappers, `--allow-empty` markers, `--skip-staging` after an explicit
`git add`, and a writer that stages its own record — seven already safe, each for its own reason,
now written down so a later reader does not "fix" them. Exactly one relied on default staging for a
file it had just created.

## Concerns

**The refusal cannot tell a rename from an unrelated pair.** It keys on the shape, not on the
files' identity — basenames change across a real migration (`concerns/x.md` →
`feedbacks/<ts>-<slug>.md`) and content changes too, so neither is a usable pair-finder. The cost
is the false positive; the mitigation is that its repair is the right move anyway.

**The second half is a procedure, and procedures decay.** The rule lives in one skill and is
referenced by two, but nothing mechanically checks that a *new* seam names its new files. What
catches that is the refusal — which is why both shipped together, and why neither should be
removed on the grounds that the other exists.

**No `git reset` on refusal** leaves the index holding what `git add -u` staged. That is deliberate
— unstaging would discard whatever the caller had staged before calling — but it means the caller
sees a populated index after a failed commit, which reads oddly until you read the message.

## Successful Development Patterns

- **Reproduce first, and record the wrong reproduction too.** The first attempt used `git mv`,
  which stages both halves and commits correctly; recording that is what stops the next reader
  concluding the defect is not there.
- **Turn a warning into a refusal when its enforcement is a human who is not present.** The warning
  was correct and useless.
- **Enumerate the callers rather than trusting the report's list.** The report named two seams; the
  code had eight, and knowing why seven are safe is the durable half.
