## 1. Overview

The mission's three mechanism tickets stay blocked on the same operator ruling they have been
blocked on since 2026-08-31. What this branch carries is one new measurement, taken while the run
was trying to hand the unit back rather than while probing for a way around the block.

## 2. Motivation

`20260830082251-make-the-claim-contend-for-one-ref-per-unit.md` asks for a unit-keyed ref pushed
create-only, and its own Considerations rule out any mechanism that leaks a ref — *a ref nothing
deletes makes every unit claimable exactly once, forever*. The measurement that closed the ticket
covered `refs/claims/*`, `refs/tags/*`, `refs/notes/*` and probe branches under `refs/heads/*`.

It had not covered the one branch the protocol's own release path must delete. A run that blocked
on the ruling and then tried to release its claim supplied that row for free, which is the only
reason it was worth taking: the standing instruction on this ticket is **read the measurement, do
not re-probe it**.
