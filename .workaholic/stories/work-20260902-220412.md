## 1. Overview

The field this ticket asked for already existed and was carried into a routine **create**; it was
missing from the **convergence diff**, so a new routine got the template's setting and an existing
one kept whatever it had. That gap is closed. The symptom the issue reported came from somewhere
this repository cannot reach, and this branch says so rather than implying otherwise.

**Highlights:**

1. `notifications` joins the converged field set at the one place four command bodies read.
2. **Absent is a value** — without that clause, *off* is the one setting convergence could never restore.
3. The diagnosis is recorded: **no workaholic routine was implicated**, and the other half is named for the developer rather than crossed to on their behalf.

## 2. Motivation

Issue #514: routine results arrived as Claude-app notifications although every routine's reporting
is designed to land in Slack and nowhere else. The ask's own investigation traced them to
one-shot, `send_later`-style check-ins bound to a **persistent session** — a class the server
will not accept a `notifications` parameter for. So the reported symptom was never a workaholic
routine's, and what this repository owned was narrower and real: the field existed, four seams
carried it, and the convergence diff did not name it.
