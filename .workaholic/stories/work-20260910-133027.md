## 1. Overview

Two readings that had drifted from what the code does are pinned back to it: a test asserting an
expectation it recomputed rather than the contract the producer states, and a `CLAUDE.md` paragraph
naming four typed transport failures in a way that read as four fallback-permitting ones.

**Highlights:**

1. The `load_per_core` assertion no longer derives its expectation from the live machine.
2. `CLAUDE.md` separates *typed* from *fallback-permitting* and names the one class that stays.
3. A new suite row pins the transport mapping and the prose against each other.

## 2. Motivation

Both defects share a shape: a statement about behaviour that nothing checked against the behaviour. The
load assertion recomputed `load1 / cores` in JavaScript and compared it against awk's `%.2f`, which
round a binary-inexact half in opposite directions — measured 2026-09-08 on four cores at `load1 =
2.51`, script `0.62` against an expected `0.63` — so it failed only at certain live loads, on the suite
the base is gated on. The transport paragraph was the same failure in prose: an adapter author reading
it alone would let an authorization refusal fall through to the connector, carrying traffic a provider
had refused the declared route permission for.

## 3. Changes

### 3-1. Make the machine-load rounding assertion deterministic ([3e5a7dad](https://github.com/qmu/workaholic/commit/3e5a7dade))

The assertion change and the producer's rounding-contract header sentence were already on the base,
landed by PR #1129 the day after the ticket was written. This drive verified each acceptance criterion
against the tree and added what was missing — a comment naming the measured divergence above the
fixture row, so the pin is not simplified back into a live recomputation.

### 3-2. Say that an authorization refusal never falls back ([1cb0a786](https://github.com/qmu/workaholic/commit/1cb0a7861))

`CLAUDE.md` keeps the four words and gains the distinction the grouping lacked: `qfs_preview_refused`
keeps the operation on the declared route, because an authorization denial stays a refusal —
`refusal-capability.sh`'s `not_permitted` doctrine, cited rather than re-derived. A new suite row pins
the mapping and the prose together; `transport/scripts/` is byte-identical, as the gate required.

## 4. Outcome

Two prose-versus-code disagreements are closed and one is now mechanically pinned, so it cannot reopen
silently. Both mechanisms are unchanged: this branch moves what is *said* about them.
