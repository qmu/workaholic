## 1. Overview

Paused host goal で native tools が利用可能なとき、routine steering は同じ `interruptible_parent` へ戻ることを要求する。Typed result が次の interruptible wait と child terminal result 回収を明示する。

**Highlights:**

1. Worker liveness と parent observation を分離する。
2. `next_action: wait_interruptibly` を返す。
3. 同じ parent に child result collection を要求する。

## 2. Motivation

Coordinator state が running で worker が生存していても、親が final response を出して観測を止めれば loop は再開していない。Paused host でも native wait が可能な場合は、schedule ではなく同じ parent の継続を機械的に証明する必要があった。

## 3. Changes

### 3-1. Keep the native parent observing ([ab9c94523](https://github.com/qmu/workaholic/commit/ab9c94523))

Final-response contract に host goal と native parent capability を加え、paused 状態では interruptible parent 以外を拒否する。Fixture は commentary 後の wait 指示と同じ coordinator による child terminal result 回収を証明する。

## 4. Outcome

Continuation evidence がない状態で resume を報告せず、利用可能な native parent は追加 user message なしで次の観測へ戻れる。Native coordinator suite は 8 tests すべて成功した。

## 6. Successful Development Patterns

- Control state、worker liveness、parent observation を別々の typed facts にすると、誤った resume claim を fixture で直接拒否できた。
