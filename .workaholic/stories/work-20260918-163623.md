## 2. Motivation

The amendment landed as `4f2da5405` while the first pull request was already merging, so the
shipped code carried the right behaviour under the wrong word. It also recorded the near miss
in full: a caller passed a correct file positionally, got `pass`/`total: 0`, and had a wrong
explanation immediately available — *`override` is neither `hard` nor `confirm`* — which is
why the ticket calls a permissive default with a ready-made rationalisation the real hazard.

The single load-bearing check is *read one parseable scan object from stdin*: it closes both
entry doors on its own, since a positional argument leaves stdin empty. The other five reasons
are diagnostic granularity, and the amendment says so lest a later change build safety on them.
