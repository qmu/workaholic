## 1. Overview

Two rows of `testInstalledCodexClock` delete a plugin layer and expect the launcher to exit 2
naming `plugin_command_missing` / `plugin_skill_missing`. The launcher first tries to recover
through `plugin-src.sh`, which deliberately reads the registry, Codex cache and clone under
`$HOME`, so the rows passed or failed with the machine's installed plugin version. The fixture now
hands the launcher an empty `HOME` and no plugin-source variables; the launcher and resolver are
byte-identical.

**Highlights:**

1. Both rows answer the same under `TMPDIR=/tmp` and `~/.cache/workaholic/…`.
2. Removing the launcher's diagnosis words makes both rows fail under both locations.
3. `local-proof.sh --repo .` on this server: `ok: true`, `complete: true`, `failed: []`, `not_run: []`.

## 2. Motivation

Two tickets described one symptom from two sides: one saw `local-proof.sh` refusing every gated
push, the other saw a bare suite run red while the proof set was green. Re-measured 2026-09-26,
both `TMPDIR` locations failed identically (`4 passed, 2 failed`, recovered to the registry tree
`1.0.389`) once the registry install reached the fixture's own version — so the split was never
about `TMPDIR`; the verdict tracked what `$HOME` held.

## 3. Changes

### 3-1. Refuse a local proof check that recovered a registry tree ([e27928ada](https://github.com/qmu/workaholic/commit/e27928ada))

Settled on the under-isolated-test side; the recovery through the newest plugin tree stays as the
deliberate unattended fallback it is.

### 3-2. Prove a missing plugin layer where a cache can recover it ([9ea62be89](https://github.com/qmu/workaholic/commit/9ea62be89))

The fixture runs every launcher call with `HOME=<fixture>/home` and without `CLAUDE_PROJECT_DIR`,
`CLAUDE_PLUGIN_ROOT`, `CLAUDE_PLUGIN_REGISTRY`, `CLAUDE_PLUGIN_CACHE`, `CODEX_PLUGIN_CACHE`,
`WORKAHOLIC_SRC_HOME`, so no tree outside the fixture is reachable.

## 4. Outcome

The declared local proof set is green on the developer's server and a bare suite run agrees with
it; no assertion was deleted or weakened.
